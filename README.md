# SplitEase

A responsive mini-project built using HTML, CSS, and vanilla JavaScript.

## Run
Open `index.html` in a modern browser. No installation or build step required.

## Files
- `index.html` — page structure
- `style.css` — styling and responsive layouts
- `script.js` — interactive functionality

Note: Google Fonts may require an internet connection. The site works offline with fallback fonts.
